## Engineering principles

- Prefer clear boundaries and explicit dependencies over tightly coupled modules.
- Design APIs around business capabilities and stable contracts.
- Make failure handling, observability, security and testing part of implementation.
- Optimise based on evidence: profiling, query plans, metrics and operational signals.
- Document trade-offs so another engineer can understand and evolve the system.
